# Requirements

## System
1. The music poster shall play a playlist through an internet connected device when interacted with
2. The system shall start the sequence within 1 second of initiation
3. The system shall be able to be interacted with intuitively
4. The system shall have visual features
5. The system shall allow for multiple posters
6. The system shall not cause danger to the user
7. The system shall be easy to set up by the user

## Networking
1. The client shall safely connect to the host device
2. The client shall safely disconnect from the host device
3. The client shall automatically connect to the host device after initial setup
4. The user shall have the ability to connect client to host via an intuitive application
5. The system shall allow multiple clients to be connected to a single device
6. The client shall automatically disconnect if powered off
7. The host-client connection shall be secure

## Hardware
1. The poster shall have the appearance of a normal poster
2. The poster shall not have any wired connections
3. The poster shall be powered via battery power
4. The poster shall have a single button with multiple purposes
5. The poster shall have display lighted accents when sequence is initiated
6. The poster shall have a sequence-on lifespan of 12 hours
7. The poster shall not overheat
8. The poster shall enter a connection mode on initial startup or when triggered via a specific button press
9. The poster shall allow for song skipping
10. The poster shall allow the user to go to the previous song
11. The poster shall be easily reproducible

## Software
1. The user shall be able to interact with the system via a GUI
2. The GUI shall allow the user to connect the poster to an external device
3. The GUI shall allow the user to configure the playlist associated with the poster
4. The GUI shall allow the user to configure the lights on the poster
5. The GUI shall allow the user to turn off the poster
6. The software shall be easy to install
7. The software shall be easy to open
8. The software shall be compatible with Windows and Mac OS
